# Weekly Summary Prompt

You are helping me do literature triage for embodied intelligence.

Input:
- A weekly markdown report generated by my local paper radar.

Tasks:
1. Pick the top 5 papers that are most likely worth full reading for a solo researcher.
2. For each selected paper, output:
   - problem
   - method
   - real-world robotics relevance
   - likely weakness
   - whether I should read now / later / skip
3. Across all papers, extract:
   - repeated technical patterns
   - common hidden assumptions
   - places where real-robot validation is still weak
   - possible low-competition research gaps
4. End with a short "idea pool" section containing 3 candidate project directions.

Requirements:
- Be skeptical about novelty claims.
- Prefer papers with clear embodied/robotics grounding.
- Distinguish sim-only work from real-robot work.
- Keep the output concise and structured.
